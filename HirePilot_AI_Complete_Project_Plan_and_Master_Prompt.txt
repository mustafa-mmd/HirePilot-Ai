Complete Project Plan: HirePilot AI

HirePilot AI will be a multi-tenant recruitment SaaS where companies create jobs, receive applications, conduct timed assessments, monitor assessment integrity, evaluate candidates with AI, and make human-controlled hiring decisions.

1. Product positioning

HirePilot AI is an AI-assisted recruitment and assessment platform that helps companies evaluate candidates through CV matching, timed assessments, coding challenges, recorded video answers, integrity monitoring, and evidence-based reports.

The system should assist recruiters—not automatically hire or reject candidates.

6. Important MongoDB rules

Every organization-owned document must contain:

organizationId

Every protected query must filter using both the resource ID and organization ID:

await Job.findOne({
  _id: jobId,
  organizationId: session.organizationId
});

Never use only:

await Job.findById(jobId);

Important indexes:

Job: { organizationId: 1, status: 1 }
Application: { organizationId: 1, jobId: 1, stage: 1 }
Candidate: { organizationId: 1, email: 1 }
Attempt: { organizationId: 1, candidateId: 1 }
IntegrityEvent: { attemptId: 1, occurredAt: 1 }
Evaluation: { applicationId: 1, evaluationType: 1 }
